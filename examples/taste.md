# Project taste (example)

Copy to the project root as `taste.md`. Overrides the owner's file and the skill's defaults for this one course.

## This course feels like
- a quiet, competent guide who has done the job and is slightly amused by it; never a cheerleader
- every mission ends with a thing on the learner's own desk

## Never
- "fun" announced; cartoon mascots; cheer; emoji punchlines
- a lecture longer than the learner's coffee

## Closest references
- Brilliant for "do the problem before the explanation"
- Lego instructions for every install step (one step per image, result shown)
- a good tabletop GM for voice and choice

## Humour here
- dry, one line, about the tool or the task, in Korean written from the intent; the narrator may admit the boring part is boring
