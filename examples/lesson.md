# lesson house rules (example)

Copy this file to your project root as `lesson.md`. The loop reads it at intake and obeys it above its own rules.

## Words
- language: Korean, 존댓말, warm but professional; teacher notes and code in English
- forbidden words: 보장, 반드시 (no absolute promises; ranges and measurements only)
- product names: never in learner-facing text; say 어시스턴트. Named tools only in the dated tool appendix.
- copy the course author wrote may not change on review runs; new or changed lines go to the waiting-on-user list

## Audience
- band E (office workers), group 7–30 in person, 1 online
- primary device: phone, 390 px wide
- learners may lack: a laptop in the room, a paid assistant account

## Time
- live session: 50 min blocks, 10 min break; never more than 12 min passive
- online mission: 5–12 min

## Facts
- curriculum facts come only from `docs/curriculum/` fact sheets; anything else is `needs fact:`
- never invent statistics, time savings, prices, dates, tool behaviour

## Game layer
- XP only for evidence (both outputs, both durations, one checklist); never for self-reported time
- no timers on judgement questions; no public ranking of individuals
- interaction types limited to the 12 in `docs/curriculum/online/00-game-design.md` §2

## Media
- diagrams: white card, large type, nothing outside boxes; follow the project's uiux taste
- screenshots: Korean UI, light theme, personal data blurred

## Loop
- bar: 8 (9 for the first lesson of each course)
- cycles: 6
- token budget: 1.5M per run
- commit: no; leave changes uncommitted and report
